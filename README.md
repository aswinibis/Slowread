# Political Study Point

A premium academic website for political philosophy, theory, economics, history, and geography.

## Prerequisites

You need to have **Node.js** installed on your computer to run this website.
1. Download and install it from [nodejs.org](https://nodejs.org/).
2. Verify installation by opening a terminal and running `node -v`.

## Getting Started

Once Node.js is installed, follow these steps to run the website:

1.  **Open a terminal** in this project folder.
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Run the development server**:
    ```bash
    npm run dev
    ```
4.  **Open your browser** and visit [http://localhost:3000](http://localhost:3000).

## Project Structure

- `app/`: Contains all the pages and routes.
- `components/`: Reusable UI components like Header, Footer, and JournalCard.
- `data/`: Mock data for the journals.
- `public/`: Static assets (images).

## Features

- **Home Page**: Featured articles and category links.
- **About Page**: Information about the research scholar.
- **Journals**: A full list of all publications.
- **Categories**: Filtered views for Philosophy, Theory, Economics, etc.
- **Responsive Design**: Works on mobile and desktop.
